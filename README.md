# Synapso

Нейронная лаборатория iOS: 3D-карта знаний в виде мозга (79 тем), уроки-миссии, практика по 7 ступеням, банк задач (301), ран и интервальные повторы. Статус темы растёт только после того, как ты сам воспроизвёл ответ, а не после чтения.

Сайт: https://ashmeyn.github.io/synapso/ (работает после включения Pages: Settings → Pages → Source: GitHub Actions).
Лаборатория-превью: https://claude.ai/artifact/BeVSnjBZMFTttMuGYTSTFV

Репозиторий создан 02.11.2026 переносом из проекта claude.ai. Первый коммит — состояние лаборатории v57 от 01.11.2026 («Телефонный режим чтения»), тег `v1.0-lab57`.

## Открыть на iPhone

1. Открой сайт в Safari. Телефонный режим включится сам: список тем вместо 3D-карты, без анимаций, батарея не садится.
2. Кнопка «Поделиться» → «На экран „Домой“» → «Добавить». Сайт откроется как отдельное приложение.
3. Если режим определился не тот, допиши к адресу `#phone` или `#desktop`.

## Перенести прогресс

Прогресс хранится в браузере (localStorage, ключи `pm.*`) отдельно для каждого сайта. Лаборатория и GitHub Pages — разные сайты, телефон и Mac между собой тоже не синхронизируются.

1. В лаборатории: НАСТРОЙКИ → «ЭКСПОРТ ПРОГРЕССА ↓». Скачается файл.
2. На новом сайте (или на другом устройстве): НАСТРОЙКИ → «ИМПОРТ ПРОГРЕССА ↑» → выбери файл.
3. Импорт заменяет прогресс целиком, а не сливает. Поэтому переносить надо с того устройства, где прогресс самый свежий.

## Собрать и проверить у себя

```
python3 scripts/build.py   # → dist/index.html (для Pages) и dist/artifact.html (для лаборатории)
npm install                # один раз: Playwright
npm test                   # smoke всех тем, телефон, десктоп
```

Открой `dist/index.html` в браузере — это готовый сайт. Сборка должна печатать `79 topics · 79 lessons · 301 bank tasks`.

## Как откатиться

1. Отменить один коммит (создаёт новый коммит-противовес, история сохраняется): `git revert <sha>`. sha смотри в `git log --oneline`.
2. Вернуть один файл к исходному состоянию переноса: `git checkout v1.0-lab57 -- content/lessons/state.md`, затем коммит.
3. Посмотреть историю урока со всеми правками: `git log -p content/lessons/<id>.md`.
4. Посмотреть, каким файл был в конкретном коммите: `git show <sha>:content/lessons/<id>.md`.

После revert в main Pages сам задеплоит прежнюю версию.

## Работа с Claude Code

1. В браузере или на телефоне: claude.ai/code → выбрать репозиторий `synapso` → написать задачу.
2. На Mac: `git clone https://github.com/ashmeyn/synapso && cd synapso && claude`.

Claude читает `CLAUDE.md` (правила проекта) сам. Порядок: Claude делает ветку и PR → CI зелёный → Claude публикует превью в лабораторию → ты смотришь и пишешь «ок» → merge в main → Pages обновляется. Готовые промпты для типовых чатов — в `docs/chat-prompts.md`.
