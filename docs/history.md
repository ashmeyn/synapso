### 02.11.2026 — проверка живого сайта, сохранность прогресса

Живой сайт https://ashmeyn.github.io/synapso/ проверен вне `npm test`: загрузка, нагрузка в покое, сохранение, экспорт, импорт. Скорость: десктоп — FCP ~0,4 с, LCP ~0,8 с (5 холодных заходов); телефон — LCP 0,6 с, на медленном 4G с процессором ×4 — 4,5 с (почти всё время — скачивание 727 КБ, 72% страницы — данные уроков). Телефон в покое — 0 rAF и 0% CPU; десктоп в покое — 4 цикла rAF, ~10% CPU на M4 Pro. Сохранение: черновики, оценки ступеней, журнал ошибок переживают перезагрузку; экспорт обычным скачиванием, импорт в чистый профиль даёт те же данные, откат работает, 5 видов испорченных файлов отклоняются.

Правки (ветка `fix/progress-persist`): при первой записи прогресса за визит сайт просит у браузера постоянное хранилище (`navigator.storage.persist()`), чтобы Safari не стёр localStorage через 7 дней без захода; иконка для «На экран „Домой“» (`apple-touch-icon`), favicon и manifest — только на Pages, исходник `engine/icons/icon.svg`; счётчик «Практика 1/7 +3» больше не теряет «+3» после оценки ступени. Не делали: убрать three.js с телефона — сцена строится через THREE и без рендера, нужна отдельная переделка.
