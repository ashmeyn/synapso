# Промпты для чатов

Каждый чат — новая сессия Claude Code на репозитории `synapso` (claude.ai/code или `claude` в клоне). Вставь «Общий старт», потом промпт чата. Порядок чатов = приоритет из docs/backlog.md. Один чат — одна задача — одна ветка и PR. Исторические промпты партий 12–24 для ChatGPT лежат в архиве проекта claude.ai: `claude/synapso/chat-prompts.md`.

## Общий старт

> Работаем над Synapso в этом репозитории. Прочитай CLAUDE.md, docs/backlog.md и последние записи docs/history.md. `engine/template.html` и `dist/*` целиком не читай — только grep и offset. Порядок: ветка от main → маленькие коммиты → `python3 scripts/build.py` и `npm test` → PR → CI зелёный → опубликуй `dist/artifact.html` в лабораторию и пришли мне скриншоты до/после (телефон 390×844 и десктоп 1440×900) → жди моего «ок» → merge в main. Телефонное — только под `PHONE` / `html.phone`, десктоп без изменений, если задача не про десктоп. Старые ключи `pm.*` не меняй, новое состояние — в новых ключах. Раскидывай независимую работу на агентов, а проверку результата отдавай отдельному агенту, который не писал код. В конце обнови docs/backlog.md (статус) и docs/history.md (запись).

## Волна 1

### Чат 1. «Выгрузка» — тема засчитывается только после воспроизведения

> Задача — «Выгрузка», и на телефоне, и на десктопе. Сейчас тема может стать «освоенной» без проверки по памяти; по моему методу статус растёт только после воспроизведения.
> 1. Сначала разберись, как сейчас считается статус (`statusOf`, `topicProgress`, `pm.steps.*`, `pm.known`, SRS) и опиши мне в 5–7 строках, что поменяется. Уже набранный прогресс не должен пропасть.
> 2. В конце теории — экран «Выгрузка»: текст урока закрыт, вопросы из раздела «Проверь себя» этого урока по одному. Я отвечаю (поле или «ответил про себя»), открываю ответ, сам оцениваю: вспомнил / частично / пусто. Ответы к вопросам брать из урока; если явного ответа нет — из шпаргалки темы, и честно пометь такие места.
> 3. Результат пишется в новый ключ `pm.*`; «вспомнил» продвигает тему, «пусто» ставит повтор на завтра в существующую систему SRS.
> 4. На телефоне без анимаций, rAF в покое = 0. Добавь тесты (телефон + десктоп).

> Задача — чтобы я мог учиться и на маке, и на телефоне с одним прогрессом. Сайт — статика на GitHub Pages, бесплатный аккаунт.
