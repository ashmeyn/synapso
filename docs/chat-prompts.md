# Промпты для чатов

Каждый чат — новая сессия Claude Code на репозитории `synapso` (claude.ai/code или `claude` в клоне). Сначала вставь «Общий старт», потом промпт чата. Исторические промпты партий 12–24 для ChatGPT лежат в архиве проекта claude.ai: `claude/synapso/chat-prompts.md`.

## Общий старт

> Работаем над Synapso в этом репозитории. Прочитай CLAUDE.md, docs/backlog.md и последние записи docs/history.md. `engine/template.html` и `dist/*` целиком не читай — только grep и offset. Порядок: ветка от main → маленькие коммиты → `python3 scripts/build.py` и `npm test` → PR → CI зелёный → опубликуй `dist/artifact.html` в лабораторию и пришли мне скриншоты до/после (телефон 390×844 и десктоп 1440×900) → жди моего «ок» → merge в main. Всё телефонное — только под `PHONE` / `html.phone`, десктоп не должен измениться. Ключи `pm.*` не трогай. В конце обнови docs/backlog.md (статус) и docs/history.md (запись).

## Чат 7. Телефон: «Корни», «Эпизод», «Выгрузка»

> Задача — новые телефонные режимы из docs/backlog.md, по одному PR на режим, в таком порядке:
> 1. «Выгрузка»: в конце урока вопросы «Проверь себя» по одному, я отвечаю по памяти, потом вижу ответ из урока и сам оцениваю. Статус темы продвигается только после выгрузки, не после прочтения.
> 2. «Корни»: перед уроком быстрые вопросы по его `prereqs` (из `ref.one` / `ref.cheat` этих тем), ответ по памяти → сверка; можно пропустить.
> 3. «Эпизод»: урок как стопка карточек, один раздел `##` на экран, листание свайпом, прогресс-точки сверху.
> Только под `PHONE`, rAF в покое остаётся 0, новые данные — в новых ключах `pm.*` без изменения старых. Перед кодом каждого режима опиши мне в 5–7 строках, как он будет выглядеть и где хранит состояние; добавь тест в tests/ на телефонном вьюпорте.

## Чат уроков (партия от ChatGPT)

> Принимаем партию уроков от ChatGPT: файлы `<id>.md`, `<id>.json` (ступени), `<id>.bank.json`. Разложи их в `content/lessons/`, `content/steps/`, `content/bank/`; новую тему добавь в `content/base/content.json`.
> 1. Прочитай каждый урок целиком: основа, ГЛУБЖЕ, 7 ступеней, банк. Проверь формат по docs/content-format.md: номер операции = позиция на карте, mission заглавными, нет `prereqs: []`, строки кода ≤ 80, нет пустых строк в коде.
> 2. Проверь код (компилируется ли по смыслу, верны ли ключи) и что каждая цель урока проверяется письменной ступенью. Проверь замечания из CLAUDE.md про ступени и банк.
> 3. Мелкое правь сам, крупное — запиши текстом для ChatGPT.
> 4. Обнови шпаргалку темы в `content/base/ref.json` (`cheat`) под урок.
> 5. `python3 scripts/build.py`, smoke-тесты по этим темам, затем `npm test` целиком.
> 6. Вердикт по каждой теме: принято / принято с правками / вернуть. Ветка → PR → опубликуй `dist/artifact.html` в лабораторию.
> 7. Добавь запись партии в docs/history.md и напиши сообщение для ChatGPT на следующую партию: что исправлено, что учесть, какие темы дальше (см. docs/backlog.md, «Контент»).
