# Промпты для чатов

Каждый чат — новая сессия Claude Code на репозитории `synapso` (claude.ai/code или `claude` в клоне). Вставь «Общий старт», потом промпт чата. Порядок чатов = приоритет из docs/backlog.md. Один чат — одна задача — одна ветка и PR. Исторические промпты партий 12–24 для ChatGPT лежат в архиве проекта claude.ai: `claude/synapso/chat-prompts.md`.

## Общий старт

> Работаем над Synapso в этом репозитории. Прочитай CLAUDE.md, docs/backlog.md и последние записи docs/history.md. `engine/app.js`, `engine/styles.css`, `engine/vendor/*` и `dist/*` целиком не читай — только grep и offset. Порядок: ветка от main → маленькие коммиты → `python3 scripts/build.py` и `npm test` → PR → CI зелёный → опубликуй `dist/artifact.html` в лабораторию и пришли мне скриншоты до/после (телефон 390×844 и десктоп 1440×900) → жди моего «ок» → merge в main. Телефонное — только под `PHONE` / `html.phone`, десктоп без изменений, если задача не про десктоп. Старые ключи `pm.*` не меняй, новое состояние — в новых ключах. Раскидывай независимую работу на агентов, а проверку результата отдавай отдельному агенту, который не писал код. В конце обнови docs/backlog.md (статус) и docs/history.md (запись).

## Волна 1

### Чат 1. «Выгрузка», честный статус и повтор вслепую

> Задача — пункты 1–3 раздела «Обучение» в docs/backlog.md, и на телефоне, и на десктопе. Сейчас тема может стать «освоенной» без проверки по памяти: любые 5 из 7 ступеней с самооценкой, ключ открывается после 2 символов, «Уже знаю» засчитывает тему по одной ступени. По моему методу статус растёт только после воспроизведения.
> 1. Сначала разберись, как сейчас считается статус (`statusOf`, `topicProgress`, `pm.steps.*`, `pm.known`, `pm.imported`, SRS, ран) и опиши мне в 5–7 строках, что поменяется. Уже набранный прогресс не должен пропасть: опиши, что станет с темами, которые сейчас «освоены».
> 2. Честный статус: тема освоена только после ступени 7 по памяти и «Выгрузки». Ключ открывается после настоящего ответа (порог предложи) или по кнопке «не знаю — покажи», которая сразу ставит «пока нет». Самооценка в 3 уровня: вспомнил / частично / нет — и в ступенях, и в «Выгрузке».
> 3. Повтор вслепую: при SRS-повторе поле ступени 7 пустое и ключ закрыт; прошлый ответ можно показать после сверки.
> 4. В конце теории — экран «Выгрузка»: текст урока закрыт, вопросы из раздела «Проверь себя» этого урока по одному. Я отвечаю (поле или «ответил про себя»), открываю ответ, сам оцениваю. Ответов к вопросам сейчас нет нигде — их напишет чат 2б. Задай формат хранения ответов (опиши в docs/content-format.md), а пока ответа нет — показывай шпаргалку темы с пометкой «ответ ещё не написан».
> 5. Результат — в новые ключи `pm.*`; «вспомнил» продвигает тему, «нет» ставит повтор на завтра в существующую систему SRS.
> 6. На телефоне без анимаций, rAF в покое = 0. Тесты (телефон + десктоп): тема не засчитывается без ступени 7 и «Выгрузки», повтор начинается с пустого поля, старый прогресс читается.
