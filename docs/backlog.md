## Телефон: следующие режимы (направление одобрено, не начато)

Все режимы держатся на методе recall-first: статус темы растёт только после воспроизведения.

1. «Корни». Перед уроком быстро вспомнить предпосылки: по `prereqs` темы показать вопросы из `ref.one` / `ref.cheat` предпосылок, ответ — по памяти, потом сверка.
2. «Эпизод». Урок как стопка карточек: один раздел `##` на экран, листание свайпом.
3. «Выгрузка». В конце урока — воспроизведение по вопросам «Проверь себя». Статус темы продвигается только после этого шага, не после прочтения.
